# Perfiles browser

Un perfil managed representa una integración aislada, no un navegador compartido. Declare nombre, objetivo, CDP local, datos persistentes locales y política de parada. No guarde cookies, datos de sesión, credenciales ni un puerto de una instalación real.

Compruebe salud del proceso y CDP antes de operar. Para Moodle/UEDI, limite el target al tablero y evite navegar a cursos cuando el flujo sea solo timeline.
