# Backup y recuperación

Respalde separadamente configuración saneada, contratos, plantillas y documentación. Las fuentes académicas originales se respaldan en su repositorio/vault autorizado; no se mezclan con la configuración del runtime.

Para recuperar: restaurar archivos de ejemplo, recrear secretos localmente, recrear perfiles browser y verificar CDP/integraciones. No restaure tokens, cookies o sesiones caducadas.
