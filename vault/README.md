# Vault / NotasCompartidas

El vault es canónico después de cambios manuales. Cada curso usa una raíz y ramas según necesidad: `Teoria`, `Laboratorio`, `Compartido` y `_Pendientes`. Las fuentes originales se preservan; los derivados mantienen trazabilidad y los adjuntos evitan duplicación.

No incluya el vault real en este starter. Cree su instancia local desde esta política.
