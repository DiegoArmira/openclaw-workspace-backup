# Agenda académica

La agenda semanal se actualiza de forma incremental: leer el documento actual, conservar cambios manuales, agregar origen/fecha/estado y registrar ambigüedades. La detección de una actividad no autoriza entrega, mensajes ni cambios externos.

Use `config.example.json`; `state.json`, capturas, actividades y agendas reales permanecen locales.
